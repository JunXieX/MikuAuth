# MikuAuth

Velocity 代理端登录验证插件。提供 Java 正版免密、基岩版免密、原版 Dialog 对话框登录、同 IP 会话免密，并支持 SQLite / MariaDB 双后端与账号迁移。

## 功能

### Java 正版免密
玩家登录时并发查询 Mojang（权威源）、Ashcon、WPME 三个验证源，任一确认该昵称存在正版账号，代理即对这条连接强制执行正版会话校验——盗版客户端无法冒充正版昵称，校验通过的玩家免密进入。

- 验证源可单独开关，超时与缓存均可配置；
- 三个源全部失败时默认按 `fail-closed` 处理（拒绝进入），避免正版昵称被离线客户端抢注；
- 正版玩家改名后，账号数据按 UUID 自动迁移到新昵称，旧昵称随之释放，不会留下"死昵称"。

### 基岩版免密
通过 Floodgate 接入的基岩版玩家由 Floodgate 自身完成身份验证，本插件识别后直接放行，不要求密码、不弹对话框。

### Dialog 对话框登录（原版 1.21.6+）
直接发送原版 `show_dialog` 数据包，玩家在图形界面里输入密码即可登录/注册，无需手打命令；客户端版本过低时自动降级为聊天栏 + Title + BossBar 提示。

### 同 IP 会话免密
离线玩家用密码登录后，在有效期内从同一 IP 再次进入时免密。会话保存在数据库中，重启代理不会丢失。

> 安全提示：同一 IP 不等于同一人（NAT、网吧、合租）。如有顾虑，可把 `session.duration-minutes` 调小，或关闭该项。

### 安全风控
- 单次连接内的密码尝试次数限制；
- 跨连接的风控：同一 IP 与同一账号两个维度累计失败达阈值即临时封禁（断线重连无法绕过）；
- BCrypt 哈希，密码为纯 Java 实现随插件打包；
- 提交限速：同 IP 短时间重复提交、同账号并发提交一律拒绝。

### 其他
- 密码自助修改，管理员可重置/删除密码、解除临时封禁；
- 登录审计日志（谁、何时、从哪、以什么方式登录）与正版昵称冲突记录；
- 玩家被目标服务器（或其上的验证网关、白名单等）拒绝进入时，把该服给出的原因**转发到玩家聊天栏**，并单独留档一条记录；
- 从 AuthMe / LibreLogin / LimboAuth 迁移账号，旧算法哈希按格式识别，玩家首次登录后自动升级为 BCrypt，无需全员重置密码。

## 运行要求

| 项目 | 要求 |
| --- | --- |
| 代理端 | Velocity 4.x（Java 25） |
| Java | **Java 25**（Velocity 4.x 的最低运行版本） |
| 必装依赖 | **packetevents-velocity**（官方完整版 jar，缺失时本插件不会加载） |
| 可选依赖 | **floodgate**（未安装时基岩版玩家走常规验证流程） |
| 认证服 | velocity.toml 中必须登记一个独立的认证服（如 limbo），未认证玩家只会被调度到该服 |

## 安装

1. 把 `MikuAuth-<版本>.jar` 放入 Velocity 的 `plugins/` 目录；
2. 安装 `packetevents-velocity`（必须为官方完整版）；
3. 在 `velocity.toml` 的 `[servers]` 中登记认证服，并把它的名字填进 `config.yml` 的 `server.auth-server`；
4. 启动代理，首次启动会生成 `plugins/MikuAuth/config.yml` 与 `messages.yml`。

> 认证服建议使用 limbo 类服务端（仅用于承接认证，不承载游戏逻辑）。

## 配置

### config.yml

| 段落 | 作用 |
| --- | --- |
| `server` | 认证服名、认证完成后的目标服 |
| `premium` | 正版验证开关、验证源开关、超时、缓存时长、改名自动迁移、fail-closed |
| `bedrock` | 基岩版免密开关与用户名前缀兜底值 |
| `session` | 同 IP 会话免密的开关、时长与是否滑动续期 |
| `audit` | 审计日志开关、保留天数、查询条数、正版冲突记录文件、后端拒绝记录文件 |
| `migrate` | 账号迁移的位置白名单 |
| `registration` | 密码长度、单 IP 账号数上限 |
| `login` | 尝试次数、认证超时、BCrypt 成本因子 |
| `dialog` | 对话框延迟发送时间 |
| `display` | Title / BossBar 开关与样式 |
| `database` | SQLite / MariaDB 连接参数 |
| `security` | 跨会话失败计数与临时封禁 |
| `commands` | 命令别名 |

配置文件内含完整中文注释。插件升级后新增的配置项会自动补进你的文件（只增不改、写入前留 `.bak`），旧文件里的失效配置项会被就地标注。

### messages.yml

所有游戏内可见文本（聊天、Title、BossBar、对话框、踢出原因、管理命令反馈）都在这里，支持全部 MiniMessage 标签，同时兼容传统 `&` 颜色代码与 `&#RRGGBB` 十六进制色。

改完配置或语言文件可执行 `/mikuauth reload` 热重载。**注意：命令别名只在启动时注册，改动别名需重启代理。**

## 命令与权限

| 命令 | 说明 | 权限 |
| --- | --- | --- |
| `/login <密码>`（别名 `l`、`log`） | 密码登录 | 玩家 |
| `/register <密码> <确认密码>`（别名 `reg`） | 注册 | 玩家 |
| `/changepassword <旧密码> <新密码> <确认新密码>`（别名 `cp`、`changepw`） | 自助修改密码 | 玩家（需已登录） |
| `/mikuauth`（别名 `/mauth`） | 管理命令，见下 | `mikuauth.admin` |

`/mikuauth` 子命令：

| 子命令 | 说明 |
| --- | --- |
| `accounts <玩家>` | 查询该玩家 IP 名下的所有账号 |
| `audit <玩家>` / `audit ip <IP>` | 查询登录审计日志 |
| `diagnose <玩家>` | 回放该昵称的完整进服判定链路 |
| `migrate <来源> <位置> [--dry-run]` | 从其他登录插件迁移账号（来源：`authme` / `librelogin` / `limboauth`） |
| `passwd <玩家>` | 交互式重置密码（密码在聊天栏输入，不会留在命令历史） |
| `setpassword <玩家> <新密码>` | 直接重置密码（保留账号） |
| `deletepassword <玩家>` | 删除密码（账号回到未注册状态，昵称可被重新注册） |
| `unbind <玩家>` | 清除正版绑定 |
| `unlock <玩家\|IP>` | 解除登录失败的临时封禁 |
| `limit [数量]` | 查看 / 临时设置每 IP 账号上限 |
| `reload` | 重载配置与语言文件 |

未认证玩家会被限制在认证服内，且只能使用认证相关命令。

## 数据存储

默认使用 SQLite，单文件、零外部依赖，适合单代理实例。多代理共享账号库时把 `database.type` 改为 `mariadb` 并填写连接参数——表名固定为 `miku_*`，请使用独立 database。

> 切换数据库类型不会自动搬运已有账号，需要自行导出/导入 `miku_players` 与 `miku_sessions` 两张表。
